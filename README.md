# 东一把

一个猜角色网页小游戏，可自定义题库，默认为东方Project题库。

## 线上版

https://touhousand-years.github.io/dongyiba/

## 本地运行

项目依赖已经随仓库准备好。使用 Node.js `>=22.13.0`，在项目目录执行：

```bash
npm run dev
```

然后打开终端显示的本地地址即可。游戏题库、猜测进度以及后台编辑内容都保存在当前浏览器的 `localStorage` 中，断网也可以使用。

构建过静态文件后，也可以直接双击项目根目录的 `启动东一把.cmd`。它会使用 Windows PowerShell 启动本地静态服务并打开浏览器；保持启动窗口运行即可使用网页，关闭窗口会停止服务。

修改页面源码后，双击项目根目录的 `更新静态页面.cmd`，可一键将最新源码编译到 `dist/client`。构建成功后刷新浏览器即可；如果仍显示旧页面，关闭启动窗口后重新运行 `启动东一把.cmd`。该脚本需要已安装 Node.js/npm 且项目依赖已就绪。

## Windows 便携版

在已经安装依赖的开发电脑上执行：

```bash
npm run package:windows
```

命令会按照 `package.json` 的版本号生成压缩包，例如 `release/dongyiba-windows-v0.1.0.zip`。把该压缩包复制到目标 Windows 电脑并完整解压，然后双击 `start-dongyiba.cmd` 即可。目标电脑不需要 Node.js、npm 或 `node_modules`，只需系统自带的 Windows PowerShell 5.1 或更高版本。

## 页面

- `/`：每日挑战、无限模式与自定义模式。每日挑战和无限模式固定使用“东方新作题库（新版测试版）”，自定义模式可以切换题库。
- `/admin`：本地维护标签、角色、别名和标签值；支持 CSV 添加、替换与导出

默认题库来源于项目目录下的 `db/东一把题库.csv`。

标签会按名称首字自动排序，并以相同顺序显示在游戏反馈表、角色编辑区和导出的 CSV 中。

如果在release版本发现数据库错误，请先尝试下载db文件夹中的最新数据库文件并替换。

修改 `db` 目录中的 CSV 后，双击项目根目录的 `更新数据库SHA.cmd`，即可重新生成项目内置数据库及其 SHA-256。完成后请把生成的 `app/default-catalog.generated.ts` 与数据库改动一起提交，避免自动更新检查误报。

CSV 的前三列固定为“角色名、别名、启用”，后续列使用“标签名（类型：类型代码）”记录标签名称和类型，例如“种族（类型：category-multi）”。支持的类型代码为 `exact`、`exact-close`、`ordered`、`category`、`exact-multi` 和 `category-multi`。添加到当前题库时按标签名称匹配（列顺序可以不同），并采用当前题库的标签类型；标签名称不同时只能替换。替换后会按 CSV 表头中的名称和类型重建标签。建议先导出当前题库作为填写模板。
“按类匹配”标签的 CSV 单元格使用“大类 > 小类”格式，例如“妖怪 > 兽类”。大类和小类都相同标绿，仅大类相同标黄，大类不同标灰。
“完全+接近匹配”使用“标签1 > 标签2 | 标签3”格式：命中标签1标绿，命中后续任一标签标黄；没有 `>` 时按只有标签1处理，兼容原完全匹配值。
“完全匹配（多标签）”直接填写多个标签值，CSV 中用 ` | ` 分隔，例如“红魔馆 | 魔法森林”；后台编辑时每行填写一个。“按类匹配（多标签）”的每组“大类 > 小类”在 CSV 中同样用 ` | ` 分隔，例如“妖怪 > 妖兽 | 神明 > 八百万之神”，后台编辑时每行填写一组；也可以只填写大类，例如“妖怪”，此时小类视为空。完全匹配模式只要任意标签值重合即标绿；按类匹配（多标签）模式的大类集合和小类集合只要各有至少一项重合即标绿，两项不必来自同一组合；同一大类的两边小类都为空时，也视为大类和小类均相同并标绿；仅有大类重合时标黄。反馈只显示实际重合的项目。

## 验证

```bash
npm test
```

测试会先构建网页，再检查页面不依赖 `/api` 请求，并验证本地题库、游戏判定和管理操作。
