# 东一把

一个东方 Project 角色猜谜网页小游戏。

## 本地运行

项目依赖已经随仓库准备好。使用 Node.js `>=22.13.0`，在项目目录执行：

```bash
npm run dev
```

然后打开终端显示的本地地址即可。游戏题库、猜测进度以及后台编辑内容都保存在当前浏览器的 `localStorage` 中，断网也可以使用。

也可以直接双击项目根目录的 `启动东一把.cmd`。它会自动启动本地服务并打开浏览器；保持启动窗口运行即可使用网页，关闭窗口会停止服务。

## 页面

- `/`：每日挑战与无限模式
- `/admin`：本地维护标签、角色、别名和标签值；支持 CSV 添加、替换与导出

后台的“恢复默认题库”会将本地编辑恢复为项目内置的 20 位角色与 5 个标签。

标签会按名称首字自动排序，并以相同顺序显示在游戏反馈表、角色编辑区和导出的 CSV 中。

CSV 的前三列固定为“角色名、别名、启用”，后续列使用“标签名（类型：类型代码）”记录标签名称和类型，例如“种族（类型：category-multi）”。支持的类型代码为 `exact`、`ordered`、`category`、`exact-multi` 和 `category-multi`。只有名称和类型都一致才视为相同标签；表头与当前题库一致时可以添加或替换，表头不同时只能替换，替换后会按新表头重建标签。建议先导出当前题库作为填写模板。
“按类匹配”标签的 CSV 单元格使用“大类 > 小类”格式，例如“妖怪 > 兽类”。大类和小类都相同标绿，仅大类相同标黄，大类不同标灰。
“完全匹配（多标签）”直接填写多个标签值，CSV 中用 ` | ` 分隔，例如“红魔馆 | 魔法森林”；后台编辑时每行填写一个。“按类匹配（多标签）”的每组“大类 > 小类”在 CSV 中同样用 ` | ` 分隔，例如“妖怪 > 妖兽 | 神明 > 八百万之神”，后台编辑时每行填写一组；也可以只填写大类，例如“妖怪”，此时小类视为空。完全匹配模式只要任意标签值重合即标绿；按类匹配（多标签）模式的大类集合和小类集合只要各有至少一项重合即标绿，两项不必来自同一组合；仅有大类重合时标黄。反馈只显示实际重合的项目。

## 验证

```bash
npm test
```

测试会先构建网页，再检查页面不依赖 `/api` 请求，并验证本地题库、游戏判定和管理操作。
